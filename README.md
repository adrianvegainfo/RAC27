# Propuestas para Cataluña, volumen 1

Web interna de trabajo para revisar propuestas locales con afinidad Antic Teatre.

## Contenido

- `index.html`: pagina principal.
- `assets/`: imagenes y logo.
- `materials/`: dossiers y fichas PDF enlazadas desde la web.
- `INSTRUCCIONES_ESTETICA.md`: criterios visuales y editoriales de la maqueta.

## Orden de propuestas

1. Ines Sybille - Simbi en aguas astronomicas
2. Raquel Klein - Negro Luz
3. Andrea El Ameri - DISLOCADAS / DOMA
4. KET o un habitat propio - APS
5. Alina Sokulska - research the f*ck out of it
6. Patricio Suarez - De como aprender a estar solx

## Publicacion

La carpeta esta preparada para publicarse como sitio estatico en GitHub Pages, Netlify o cualquier hosting de HTML.

Por privacidad, se recomienda repositorio privado: contiene contactos, enlaces de Drive y dossiers de artistas.
